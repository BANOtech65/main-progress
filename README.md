# main-progress

A Claude Code mod: a progress bar above the prompt showing how far the main agent's work is. It follows the app's task list automatically, or the model can report progress with its own `progress` tool.

## Install

At the prompt of a terminal session:

```
/plugin install main-progress --marketplace BANOtech65/main-progress
```

From a shell:

```
claude plugin install main-progress --marketplace BANOtech65/main-progress
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `BANOtech65/main-progress`, then Add plugin.

Answer `y` to add the marketplace, then choose a scope.
